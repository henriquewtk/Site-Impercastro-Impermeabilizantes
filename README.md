# Impercastro Impermeabilizantes — site

Landing page da Impercastro, loja especializada em impermeabilização em Rio Verde (GO).

Feita com **Astro** e gera HTML estático: carrega rápido, é bem lida pelo Google e quase não usa JavaScript (só o menu do celular e a animação de entrada).

## Rodar no computador

Precisa do [Node.js](https://nodejs.org) 20 ou mais novo.

```bash
npm install
npm run dev
```

Abra http://localhost:4321.

Para gerar a versão final: `npm run build` (sai na pasta `dist/`).
